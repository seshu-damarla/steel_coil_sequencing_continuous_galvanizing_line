# Dataset Attribution and License

The CGL benchmark data in `data/` are third-party research data and are not covered by this repository's MIT code license.

Dataset:

Nicolás Álvarez-Gil (2021), “Problem instances of the sequencing problem of a steel continuous galvanizing line,” Mendeley Data, Version 2.

DOI: https://doi.org/10.17632/v357z2ncbh.2

Mendeley Data record: https://data.mendeley.com/datasets/v357z2ncbh/2

The Mendeley Data record lists the dataset license as **Creative Commons Attribution 4.0 International (CC BY 4.0)**.

When redistributing or reusing the data, preserve attribution to the original dataset creator(s), the DOI, and the CC BY 4.0 license.

Related data article:

N. Álvarez-Gil, S. Álvarez García, R. Rosillo, D. de la Fuente, “Problem instances dataset of a real-world sequencing problem with transition constraints and asymmetric costs,” Data in Brief 41 (2022), 107844. https://doi.org/10.1016/j.dib.2022.107844
